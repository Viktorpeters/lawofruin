## Usage notes

- Save the actual image files into this folder using the filenames listed above.
- Match every image to the person before using it; automated and search results can be misidentified.
- Preserve archival black-and-white images as they are; do not describe them as original colour photographs.
- Follow the license and attribution requirements on each individual source page.
- `The Arellano Félix brothers` should use a group photograph if available; `King Solomon` is an engraving, not a photograph.
